# UniReps 2026 extended abstract: how to read and review

**Paper:** *In Llama, Saying "I Don't Know" Tracks Entity Popularity More Than Knowledge*
**Venue:** UniReps workshop at NeurIPS 2026, extended-abstract track (4 pages of main text, NeurIPS template, double-blind).
**Deadline:** OpenReview, 11 Oct 2026, 12:00 UTC.

## Catch up first

New to this draft? Read [`WHAT_CHANGED.md`](WHAT_CHANGED.md) (10 minutes). It covers what the reviewers asked in three rounds, what we changed, the new experiments and how each claim moved. The current status of every claim is in [`CLAIMS.md`](CLAIMS.md), and the dated record of every decision, failure and fix is in [`LAB_LOG.md`](LAB_LOG.md).

## Read

Open [`main.pdf`](main.pdf); GitHub shows it in the browser. Pages 1-4 are the paper, references start on page 5, and appendices A-H follow. A 10-minute read: the abstract, Figure 1, Section 3.1, and the first paragraph of Section 3.2.

## Review

Pick whichever is easier:

1. **Line comments (preferred).** Open the pull request for branch `emo_attyachar_2.0`, go to *Files changed*, find `paper_2.0/main.tex`, and click `+` next to a line. One comment per point.
2. **Issues.** Open a GitHub issue titled `[paper] <section>: <point>`, for example `[paper] 3.2: Gemma sentence overstated`.

Useful labels for a comment: **error** (something is wrong), **unclear** (hard to follow), **missing** (a reader needs it), **cut** (not needed in 4 pages).

Please do not:
- type numbers into `main.tex`. Every number is a macro in `numbers.tex`, generated by `make_numbers.py` from the result files. If a number looks wrong, flag it and we trace it to its source.
- add author names or affiliations. The submission is anonymous.
- add claims without a result behind them. The round-3 chair made "no new claims" a condition of acceptance.

## Questions the authors still have to settle

- The author list and order, the reciprocal reviewer and the OpenReview profiles.
- The title is scoped to Llama. Under a prompt that permits "I don't know" (E9), Gemma also tracks popularity. Do we keep the scope?
- The LLM-use disclosure required at submission.
- Whether to mention the exploratory OLMo-2 run as future work. It is not in the paper (`analysis/explore_olmo.txt`).

## Rebuild

From this folder, with the data repository as its parent folder:

```
python make_numbers.py          # regenerates numbers.tex from ../results
latexmk -pdf main.tex           # builds main.pdf
```

The figure scripts are `python figures/fig_*.py`.
